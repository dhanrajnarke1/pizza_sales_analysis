# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes a **pizza sales dataset using PostgreSQL** to uncover key business insights related to sales performance, customer ordering patterns, product performance, and revenue trends.

The analysis uses SQL techniques ranging from basic data retrieval and aggregation to advanced analytical methods such as **Joins, Subqueries, Common Table Expressions (CTEs), and Window Functions**.

The objective of this project is to transform raw transactional sales data into **actionable business insights** that can support data-driven decisions related to sales, product performance, and operations.

---

## 🎯 Business Objectives

The analysis focuses on answering important business questions such as:

* How much revenue has the business generated?
* How many orders have been placed?
* Which pizza types and sizes are most popular?
* Which pizza categories generate the highest revenue?
* What are the peak ordering hours?
* How does revenue change over time?
* Which pizzas perform best within each category?
* Are there noticeable monthly or seasonal sales patterns?

---

## 🔍 Key Analysis Performed

### 📊 Sales Performance

* Calculated **total number of orders**.
* Calculated **total revenue generated**.
* Calculated average order and sales-related metrics.
* Analyzed overall sales performance.

### 🍕 Product Analysis

* Identified the **highest-priced pizza**.
* Identified the **most frequently ordered pizza size**.
* Determined the **top-selling pizzas based on quantity**.
* Identified pizzas generating the **highest revenue**.
* Analyzed pizza performance across different categories.

### 📈 Category Analysis

* Calculated category-wise sales.
* Analyzed revenue contribution by pizza category.
* Identified the highest revenue-generating category.

### ⏰ Time-Based Analysis

* Analyzed hourly order trends.
* Identified **peak business hours**.
* Calculated the average number of pizzas ordered per day.
* Analyzed monthly revenue trends.
* Identified the month with the highest revenue.

### 📌 Advanced SQL Analysis

* Used **Joins** to combine data from multiple tables.
* Used **Aggregate Functions** for sales and revenue calculations.
* Used **Subqueries** for advanced filtering and comparisons.
* Used **Common Table Expressions (CTEs)** to simplify complex queries.
* Used **Window Functions** to calculate cumulative revenue.
* Used **Ranking Functions** to identify top-performing pizzas within each category.
